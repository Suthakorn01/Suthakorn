QR Code Scanner

สแกน QR Code เพื่ออ่านข้อมูลที่ซ่อนอยู่ภายใน รองรับการสแกนผ่านกล้องและรูปภาพจากเครื่อง

กดเปิดกล้อง แล้วหันกล้องไปที่ QR Code

ข้อมูลที่อ่านได้จาก QR Code

ระบบจะแสดงข้อมูลจริงที่ถูกบันทึกไว้ใน QR Code

วิธีใช้งาน
1. กดเปิดกล้องสแกน
2. นำ QR Code มาไว้ในกรอบกล้อง
3. รอระบบอ่านข้อมูล
4. ข้อมูลจะแสดงด้านล่าง
5. กดคัดลอกเพื่อนำไปใช้งาน

หมายเหตุ: QR Code ที่ไม่มีข้อมูลจริง จะไม่สามารถถอดข้อมูลออกมาได้ เว็บไซต์ต้องเปิดผ่าน HTTPS และอนุญาตให้ใช้กล้อง
