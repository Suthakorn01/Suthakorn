ระบบสแกนบาร์โค้ดเส้น เน้น CODE 39 และ CODE 128 พร้อมตรวจสอบรหัส
1. กล้องสแกนบาร์โค้ด

จัดบาร์โค้ดให้อยู่กลางภาพ เห็นเส้นทั้งหมด และถือกล้องให้นิ่ง

กดเปิดกล้องเพื่อเริ่มสแกน

2. ผลการอ่านบาร์โค้ด

รหัสที่อ่านได้จากลายเส้นโดยตรง

ยังไม่มีข้อมูล
ชนิดบาร์โค้ด -
อ่านซ้ำตรงกัน 0 / 3
Check Digit ยังไม่ตรวจสอบ
3. ตรวจสอบกับเลขใต้บาร์โค้ด

ตัวอย่างจากภาพของคุณคือ 51080-1 กรอกเลขที่มองเห็นบนกระดาษเพื่อเทียบกับผลการสแกน

ยังไม่ได้ตรวจสอบ

รูปแบบที่รองรับ
CODE 39 / CODE 128 / EAN-13 / EAN-8
UPC-A / UPC-E / ITF / CODABAR

หมายเหตุ: การอ่านซ้ำ 3 ครั้งช่วยกรองการอ่านที่ไม่สม่ำเสมอ แต่ไม่ยืนยันว่าตรงกับกระดาษ ต้องใช้ช่องตรวจสอบเลขต้นฉบับด้วย
