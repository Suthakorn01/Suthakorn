ระบบอ่านบาร์โค้ดเส้น พร้อมตรวจสอบความถูกต้องก่อนนำรหัสไปใช้งาน
1. สแกนบาร์โค้ด

วางบาร์โค้ดให้เห็นเส้นทั้งหมด กล้องควรอยู่ในระยะที่ภาพคมชัด

กดเปิดกล้องเพื่อเริ่มสแกน

2. ผลการอ่านเบื้องต้น

ระบบจะแสดงรหัสเมื่ออ่านซ้ำตรงกัน 3 ครั้ง หรืออ่านได้จากภาพถ่าย

ยังไม่มีข้อมูล
ชนิดบาร์โค้ด-
จำนวนครั้งที่อ่านตรงกัน0 / 3
ตรวจสอบ Check Digitรอตรวจสอบ
3. ยืนยันกับเลขที่พิมพ์ใต้บาร์โค้ด

กรอกตัวเลขหรือรหัสที่มองเห็นอยู่ใต้เส้นบาร์โค้ดบนกระดาษ ระบบจะเทียบกับผลที่กล้องอ่านได้แบบตรงตัว

ยังไม่ได้ยืนยันข้อมูล

ข้อควรทราบ

• EAN-13, EAN-8 และ UPC-A จะตรวจสอบ Check Digit ให้
• Code 128 และ Code 39 จะต้องเทียบกับเลขที่พิมพ์ใต้บาร์โค้ด เพราะไม่สามารถยืนยันความถูกต้องด้วย Check Digit มาตรฐานเดียวกันได้ทุกกรณี
• การอ่านซ้ำ 3 ครั้งช่วยลดความผิดพลาด แต่ไม่ใช่หลักฐานว่ารหัสตรงกับสินค้าจริง
• หากต้องการยืนยันสินค้า ต้องเทียบกับฐานข้อมูลต้นฉบับด้วย
